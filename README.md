# Лабораторная работа №1 — FSM для NPC

## Реализация
Проект рассчитан на Unity 2D и содержит два типа противников:

- `NormalEnemyAI`: поле зрения 180°, дальность обнаружения, проверка препятствий через Physics2D.Raycast.
- `TeleportEnemyAI`: периодическое 360°-сканирование в радиусе 1 м и телепортация с cooldown, максимальной дистанцией и проверкой препятствий.

Оба противника используют базовые состояния:
`Idle`, `Patrol`, `Chase`, `Attack`, `Search`, `Death`.

Телепортирующийся противник дополнительно использует `Teleport`.

## Подключение в Unity
1. Создайте сцену 2D.
2. Игроку назначьте Tag `Player` и добавьте `PlayerController 2D`.
3. Создайте стены с Collider2D и поместите их в слой препятствий.
4. На обычного врага добавьте `NormalEnemyAI`.
5. На телепортирующегося врага добавьте `TeleportEnemyAI`.
6. В инспекторе укажите `Obstacle Mask`, `Player Mask`, скорость, радиусы, точки патрулирования и параметры атаки.
7. Для точек патрулирования создайте пустые GameObject и перетащите их в массив `Patrol Points`.
8. Если ссылка на игрока не задана вручную, скрипт найдёт объект с Tag `Player` автоматически.

## Состояния и обозначения схемы
- I — Idle
- P — Patrol
- D — Detect / обнаружение
- F — Fight / Attack
- S — Search
- T — Teleport
- De — Death

Состояние Death является финальным: NPC прекращает обычную логику и уничтожается после короткой задержки.
